## Hướng dẫn cài đặt
1. Clone dự án: `git clone <link-repo>`
2. Tạo venv: `python -m venv venv`
3. Kích hoạt venv: `venv\Scripts\activate` (Windows)
4. Cài thư viện: `pip install -r requirements.txt`
5. Chạy ứng dụng: `python src/app.py`
